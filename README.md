# Portfolio Website | Frontend Practice

## Project Overview

This repository contains my early portfolio website development experiments, created in August 2024 while learning frontend web development.

The project focuses on designing personal portfolio interfaces using HTML and CSS, exploring webpage layouts, navigation structures, typography, and styling techniques.

The repository includes two different implementations developed during my initial exploration of frontend design.

## What I Worked On

- Created portfolio landing page layouts using HTML and CSS.
- Designed navigation bars, introductory sections, and portfolio interface elements.
- Practiced CSS Flexbox for positioning and aligning webpage components.
- Experimented with typography, colors, hover effects, and CSS variables.
- Designed a footer containing social media icons using Font Awesome.
- Created the visual layout of a CV download button and newsletter subscription section.
- Explored different approaches to structuring and styling personal portfolio websites.

## Tech Stack

- HTML5
- CSS3
- Font Awesome
- Google Fonts

## Project Structure

### Root Directory

- `index.html` – Initial portfolio landing page implementation.
- `style.css` – Basic layout and styling experiments.

### Folder1

- `index.html` – Alternative portfolio interface featuring navigation, introduction, newsletter section, and footer.
- `style.css` – Styling for the alternative portfolio layout.
- `assets/` – Image assets used in the project.

## Repository Status

This repository is archived and preserved as a record of my early frontend development learning and portfolio design experiments from August 2024.

The implementations focus primarily on interface design and CSS styling rather than complete portfolio functionality. The repository is not actively maintained, but the source code remains publicly available for reference.
